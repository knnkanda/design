# design

KNN シリーズ（Paul Kanda / KNNポール神田 氏の個人開発アプリ群）で共通して使うデザインルールをまとめたリポジトリです。

## 収録ファイル

| ファイル | 内容 |
|---|---|
| [knn-app-color-scheme/SKILL.md](knn-app-color-scheme/SKILL.md) | KNN アプリのカラースキーム・背景アニメーション・レイアウトの型 |

新しい KNN アプリを作るときは、このリポジトリの SKILL.md の値をそのまま流用します。アイコン絵文字とアプリ名だけを用途に合わせて変え、色味・透明度・角丸のルールは変えないのが基本です。

---

## コンセプト

- **紫からピンクへ**、ゆっくり揺らぎ続けるグラデーション背景
- その上に**半透明のガラス風カード**を重ねて情報を載せる
- 派手すぎず、上品で、少し未来的な雰囲気

## カラー

### カラートークン

| 用途 | 値 |
|---|---|
| 背景グラデーション | `linear-gradient(135deg, #6d28d9 0%, #9333ea 25%, #c026d3 50%, #db2777 75%, #a855f7 100%)` |
| 背景サイズ（揺らぎ用） | `background-size: 220% 220%` |
| 文字（基本） | `#ffffff` |
| 文字（補助・ラベル） | `rgba(255,255,255,0.7)` 〜 `rgba(255,255,255,0.75)` |
| カード背景 | `rgba(255,255,255,0.12)` 〜 `rgba(255,255,255,0.14)` |
| カード枠線 | `rgba(255,255,255,0.25)` 〜 `rgba(255,255,255,0.35)` |
| ボタン（主・白背景） | 背景 `rgba(255,255,255,0.9)` / 文字色 `#7e22ce` |
| 強調文字・注意書き | `#ffd9ec` または `#ffe9f7` |

### グラデーションの色の並び

左上（135度）から右下へ、次の順に色が移ります。

1. `#6d28d9`（深い紫）
2. `#9333ea`（紫）
3. `#c026d3`（マゼンタ寄りの紫）
4. `#db2777`（ピンク）
5. `#a855f7`（明るい紫）

端の色は紫系で閉じているので、アニメーションでどの位置が見えても色が急に変わらないようになっています。

### 白系の文字色の使い分け

- **本文・見出し**：`#ffffff`
- **ラベル・補足**：`rgba(255,255,255,0.7)` 前後。主役より一段下げる役割
- **注意書き・強調**：`#ffd9ec` などの淡いピンク。白一色だと単調になるときに、ピンクのアクセントとして使う

## 背景アニメーション

背景は止まった画像ではなく、グラデーションの位置がゆっくり動き続けます。

```css
@keyframes knnGradientShift {
  0%   { background-position: 0% 30%; }
  50%  { background-position: 100% 70%; }
  100% { background-position: 0% 30%; }
}
.knn-bg {
  background: linear-gradient(135deg, #6d28d9 0%, #9333ea 25%, #c026d3 50%, #db2777 75%, #a855f7 100%);
  background-size: 220% 220%;
  animation: knnGradientShift 18s ease-in-out infinite;
}
```

- **周期は 18 秒**。15〜20 秒の範囲に収めます
- 速すぎると落ち着かないため、短くしないでください
- `ease-in-out` で往復させ、端でのカクつきを防ぎます
- 背景サイズ `220% 220%` は、位置を動かすための余白です

## ガラス風カード

情報を載せる面は、背景が透けて見える半透明のカードにします。

- 背景色：`rgba(255,255,255,0.12)` 〜 `0.14`
- 枠線：`1px` 程度の `rgba(255,255,255,0.25)` 〜 `0.35`
- ぼかし：`backdrop-filter: blur(6px)`（対応していない環境では単に半透明になります）
- 角丸：`20px` 前後

透明度を上げすぎると文字が背景に埋もれます。0.12〜0.14 の範囲に留めてください。

---

## ボタン・入力欄（ピル型）

入力欄もボタンもタブも、すべて `border-radius: 999px` の**ピル型（完全な半円の端）**で統一します。

| 要素 | 通常時 | 選択中・主要 |
|---|---|---|
| タブ | 透明背景＋白文字＋枠線 | 白背景（`rgba(255,255,255,0.9)`）＋紫文字（`#7e22ce`） |
| 入力欄 | ガラス風カードと同じ半透明背景＋白文字 | フォーカス時は枠線を明るく |
| 主ボタン | 白背景（`0.9`）＋紫文字（`#7e22ce`） | — |

白いボタンは背景の紫〜ピンクの中で一番目立つ要素になります。画面に置くのは、その画面での主要なアクション 1 つに限ると見やすくなります。

---

## 丸み・影・枠

- **アプリ全体のカード**：`border-radius: 28px`
- **カード・パネル**：`border-radius: 20px` 前後
- **アイコン**：円形（`border-radius: 50%`）、半透明の背景と枠線
- **影**：`0 20px 50px rgba(120,40,140,0.35)`。紫味のある影で、背景となじませる

---

## レイアウトの型

- 全体は**最大幅 400px 程度のスマホ風カード**
- ヘッダーは「丸いアイコン（絵文字またはシンプルな線画）＋アプリ名＋日付」
- タブは横並びのピル型ボタン
- 余白は縦方向に広めに取り、カード同士の間隔も揃える

---

## フォント

- **Noto Sans JP**（Google Fonts から読み込み）
- 見出しは太字（700）、本文は標準（400〜500）

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;500;700&display=swap" rel="stylesheet">
```

## 使い方のルール

1. 新しい KNN アプリを作るときは、この配色・アニメーション・レイアウトの型をそのまま使う
2. 変えてよいのは、アイコン絵文字とアプリ名、データの内容だけ
3. 色の値や透明度、角丸のルールは変えない。変える必要がありそうな場合は、先にこのリポジトリを更新する
4. 色をさらに追加する場合は、上のカラートークンに加えてから使う

---

## 注意点

- **文字の読みやすさ**：白の文字はピンク寄りの背景の上で見えにくくなることがあります。補助文字（0.7 前後）は長文に使わないでください
- **動きの強さ**：背景の揺らぎは常時動きます。長時間見る画面では、動きを止められるようにする（`prefers-reduced-motion` への対応）ことも検討してください。現在の SKILL.md にはこの指定は含まれていません
- **透明度の調整**：ガラス風の見た目は透明度に依存します。背景が変わる場合は、読めるかを実機で必ず確認してください
