# KNN アプリ カラースキーム

Paul Kanda(KNNポール神田)氏の個人開発アプリ群で使う、統一されたビジュアルデザインのルール。
参考元: https://github.com/knnkanda/countdown_timer (Timerアプリのスクリーンショット)

## コンセプト

紫からピンクへ、ゆっくりと色が揺らぎ続けるグラデーション背景。
その上に半透明の「ガラス」のようなカードを重ねて、情報を乗せる。
派手すぎず、上品で、少し未来的な雰囲気。

## カラートークン

| 用途 | 値 |
|---|---|
| 背景グラデーション | `linear-gradient(135deg, #6d28d9 0%, #9333ea 25%, #c026d3 50%, #db2777 75%, #a855f7 100%)` |
| 背景サイズ(揺らぎ用) | `background-size: 220% 220%` |
| 文字(基本) | `#ffffff` |
| 文字(補助・ラベル) | `rgba(255,255,255,0.7)` 〜 `rgba(255,255,255,0.75)` |
| カード背景 | `rgba(255,255,255,0.12)` 〜 `rgba(255,255,255,0.14)` |
| カード枠線 | `rgba(255,255,255,0.25)` 〜 `rgba(255,255,255,0.35)` |
| ボタン(主・白背景) | 背景 `rgba(255,255,255,0.9)` / 文字色 `#7e22ce` |
| 強調文字・注意書き | `#ffd9ec` または `#ffe9f7` |

## 背景アニメーション(CSS)

```css
@keyframes knnGradientShift {
  0%   { background-position: 0% 30%; }
  50%  { background-position: 100% 70%; }
  100% { background-position: 0% 30%; }
}
.knn-bg {
  background: linear-gradient(135deg, #6d28d9 0%, #9333ea 25%, #c026d3 50%, #db2777 75%, #a855f7 100%);
  background-size: 220% 220%;
  animation: knnGradientShift 18s ease-in-out infinite;
}
```

18秒周期。速すぎると落ち着かないので、必ずゆっくり(15〜20秒)にする。

## レイアウトの型

- 全体は最大幅 400px 程度のスマホライクなカード(`border-radius: 28px`、影 `0 20px 50px rgba(120,40,140,0.35)`)
- ヘッダーに丸いアイコン(絵文字 or シンプルなライン)+ アプリ名 + 日付
- タブ切り替えは「ピル型」(`border-radius: 999px`)の横並びボタン。選択中のタブだけ白背景+紫文字、それ以外は透明+白文字
- 入力欄・ボタンもすべて角丸ピル型(`border-radius: 999px`)で統一
- カードには軽いガラス効果(`backdrop-filter: blur(6px)`)を付ける
- フォントは `'Noto Sans JP'`(Google Fonts経由で読み込み)

## 使うとき

- 新しいKNN個人アプリ(睡眠管理・時間管理・移動管理・自炊アプリなど)を作るときは、この配色・アニメーション・レイアウトの型をそのまま流用する
- 用途によってアイコン絵文字やアプリ名だけを変え、色味やコンポーネントの角丸・透明度のルールは変えない
- これにより「KNNシリーズ」として見た目に統一感が出る
